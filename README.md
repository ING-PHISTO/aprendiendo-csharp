## 📁 Estructura

Cada carpeta es un proyecto de consola independiente:

```
aprendiendo-csharp/
├── HolaMundo/        → mi primer programa en C#
└── ...               → un proyecto por tema o reto
```

## ▶️ Cómo correr un proyecto

Necesitas el [SDK de .NET 10](https://dotnet.microsoft.com/download). Luego:

```bash
cd HolaMundo
dotnet run
```
