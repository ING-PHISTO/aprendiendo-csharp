Soy Ingeniero de Sistemas con experiencia en infraestructura, redes y desarrollo web. Ahora me estoy enfocando en el **desarrollo backend con .NET**.

## 📁 Estructura

Cada carpeta es un proyecto de consola independiente:

```
aprendiendo-csharp/
├── HolaMundo/   → mi primer programa en C#
├── Dia01/       → variables e interpolación
├── Dia02/       → tipos de datos (ficha de VLASS)
├── Dia03/       → secuencias de escape y cadenas literales
├── Dia04/       → decisiones (if / else)
├── Dia05/       → bucles
├── Dia06/       → arrays y listas
└── ...          → un proyecto por tema o reto
```

## ▶️ Cómo correr un proyecto

Necesitas el [SDK de .NET 10](https://dotnet.microsoft.com/download). Luego:

```bash
cd HolaMundo
dotnet run
```
